# Continuous Innovation Framework

## Core Mindset

- Building a business model requires a **search mindset, not an execution mindset**

## The Goldilocks Problem

- Most entrepreneurs go either too broad (watered down, undifferentiated) or too narrow (local maximum trap)
- Solution: Split your "big idea canvas" into multiple specific canvases to go simultaneously broad and narrow

## Canvas Scope Rules

- **One business model story per Lean Canvas** - if you can't fit it on one page, you went too broad
- Start with specific customer in mind, even if building mainstream product (e.g., Facebook started with Harvard students only)
- Each additional canvas should be narrow and specific to one customer segment or model variant

## Exploring Variants

- Go broad across multiple canvases by sketching different variants of same idea
- Different customer segments require separate canvases (consumers vs businesses)
- Different business models within same segment require separate canvases (e.g., multiple business models for B2B photo-sharing)

## Business Model Archetypes

- Three basic types: **direct, multisided, and marketplace**
- If mixing multiple archetype types on one canvas, split them into separate canvases
- Each canvas should represent only one archetype

## Key Principle

- Multiple narrow canvases beat one broad canvas - specificity enables meaningful differentiation
